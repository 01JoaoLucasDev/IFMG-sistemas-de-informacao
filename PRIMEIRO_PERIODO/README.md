# Organização por Períodos

Este repositório está organizado em pastas de acordo com os períodos do curso de Sistemas de Informação no IFMG. Cada pasta de período reúne as disciplinas, atividades, exercícios e projetos desenvolvidos durante aquela etapa da graduação.

Essa organização facilita a localização dos conteúdos e acompanha a evolução do curso ao longo dos períodos. Dentro de cada pasta, um README específico apresenta as disciplinas e os materiais correspondentes ao respectivo período.
